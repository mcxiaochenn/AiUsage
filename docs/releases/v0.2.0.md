# AiUsage v0.2.0

AiUsage v0.2.0 将 Android 稳定版从 Codex 额度监看扩展为本地优先的多 Provider 用量与余额应用，新增 DeepSeek 和 Xiaomi MiMo，同时保留现有 Codex 配额、Credits 与 Profile Token 统计。

## 主要变化

- 统一的 Codex、DeepSeek、MiMo 多账户选择、缓存、刷新、诊断和演示体验。
- DeepSeek 使用官方 `GET /user/balance`，按币种分别展示总余额、赠送余额与充值余额，不进行汇率换算。
- MiMo 支持小米账号一次登录；密码不持久化，验证码、短信或 MFA 在受域名限制的小米官方网页中完成。
- MiMo 展示按量余额、现金/赠送/冻结/透支字段，并在账号存在 Token Plan 时展示套餐用量。
- 兼容 MiMo 当前 HTTP 302 登录跳转与 Xiaomi Passport JSON 响应；无 Token Plan 账号显示合法空态。
- Provider 凭据只保存在平台安全存储，SQLite 和诊断不会记录 API Key、OAuth Token、Cookie、原始密码或原始账户 ID。

## 下载

- `AiUsage-v0.2.0-android-arm64.apk`：适用于 arm64 Android 设备的直接安装包。
- `AiUsage-v0.2.0-android-arm64.aab`：供后续应用商店提交，不可直接安装。
- `AiUsage-v0.2.0-SHA256SUMS.txt`：发布产物的 SHA-256 校验值。

正式产物继续使用 AiUsage v0 发布证书签名，仅包含 `arm64-v8a` 与 `libai_usage_core.so`，不包含 Flutter Debug snapshot、Vulkan validation layer 或其他 ABI engine。

## 升级说明

- 可从 v0.1.0 直接覆盖安装，现有 Codex 凭据、设置、历史和缓存会保留。
- 新增 DeepSeek 和 MiMo 账户需要用户主动提供对应凭据并完成一次在线验证。
- 后台自动刷新仍默认关闭；操作系统可能延迟或取消后台任务。

## 已知限制

- 当前仅发布 Android arm64 APK/AAB；Windows、macOS、Linux 和 iOS 仍为源码级实验支持。
- MiMo 使用未公开的控制台 API，登录、Cookie 和响应 schema 可能随上游调整而失效。
- Codex Profile、Usage 与 `/v1/me` 同样不是面向第三方承诺稳定的公开 API。
- 没有 Token Plan 的 MiMo 账户只显示按量余额；不会伪造套餐额度。
- 当前没有自动更新器或 Google Play 发布，需要从 GitHub Release 手动升级。

本项目与 OpenAI、DeepSeek、小米均无隶属或官方合作关系。
