# AiUsage v0.2.1

AiUsage v0.2.1 重新整理项目文档和移动端发布流程，Android 现提供 universal 与三种分 ABI APK，iOS 首次提供由 macOS CI 构建的未签名 IPA。

## 主要变化

- 根 README 收敛为面向首次访问者的中英文落地页，详细安装、平台、架构、安全、开发和路线图迁移到 `docs/`。
- Android 成为当前主要支持平台；iOS 作为重点适配平台，由 macOS CI 验证编译，但因缺少物理设备仍未完成真机测试。
- Windows、macOS 和 Linux 转入后期适配流程，当前 Release 不提供桌面安装产物。
- `app/pubspec.yaml` 成为唯一人工应用版本入口；Android `versionCode` 与 iOS `CFBundleVersion` 使用当前 Tag 所在提交的完整仓库 commit 数。
- Release 不再生成 AAB，改为四个 Android APK 与一个 unsigned IPA；构建会校验版本、ABI、Rust 核心、调试资源、签名和资产矩阵。
- GitHub Actions 构建 Job 保持只读权限，只有最终发布 Job 可以写入 Release。

## 下载

- `AiUsage-android-release-arm64-v8a.apk`：绝大多数现代 Android 手机，推荐。
- `AiUsage-android-release-universal.apk`：不确定设备架构时选择，体积较大。
- `AiUsage-android-release-armeabi-v7a.apk`：较旧的 32 位 ARM 设备。
- `AiUsage-android-release-x86_64.apk`：64 位 x86 模拟器或少量设备。
- `AiUsage-ios-release-unsigned.ipa`：未签名 iOS 产物，需要用户自行签名。
- `AiUsage-SHA256SUMS.txt`：全部发布附件的 SHA-256。

项目暂无 Google Play、App Store 或其他应用商店上架计划。Android 用户应从 GitHub Release 安装；iOS IPA 不包含 Apple 证书或 Provisioning Profile，无法像 App Store 应用一样直接安装。

## 升级说明

- Android 包名和发布证书未变，可从 v0.2.0 覆盖安装并保留凭据、设置和缓存。
- Android 32 位 x86 已不受 Flutter 支持，因此不提供 `x86` APK。
- v0.2.0 的 AAB 仅作为历史附件保留，v0.2.1 不再发布 AAB。

## 已知限制

- iOS 仅通过 macOS CI 编译和封装，没有物理设备验收；Keychain、登录、文件选择、通知和后台任务可能存在未发现问题。
- Codex 和 MiMo 依赖的部分内部接口可能随上游变化；Profile Token 统计也可能按日延迟。
- Android 后台执行受系统和厂商策略影响，不能保证固定周期。
- Windows、macOS 和 Linux 当前不提供安装支持。

AiUsage 是非官方项目，与 OpenAI、DeepSeek、小米没有隶属或官方合作关系。
