# AiUsage v0.3.0

AiUsage v0.3.0 聚焦账户管理、Provider 品牌化、关于页体验和 Codex Token 统计交互。

## 主要变化

- Provider 名称与图标统一为 ChatGPT、DeepSeek 和 Xiaomi MiMo。
- 账户页支持自定义名称、重命名、Provider 专属账户标识和更清晰的响应式卡片布局。
- 概览顶部账户卡片会即时同步当前账户的自定义名称。
- 优化 Device Code 授权、`auth.json` 导入和 MiMo 添加账户流程。
- 关于页改为应用信息、开发者、开源链接和版权分组卡片，并内置开发者头像。
- Codex Token 热力图支持每日、每周和累计视图，以及点击/悬停查看准确 Token 用量。
- 诊断页增加清空日志入口；关于页保留受保护的数据自毁功能。

## 安全与限制

- 凭据仍仅保存于系统安全存储；完整 API Key、Token、Cookie 和密码不会写入 SQLite、诊断或日志。
- 开发者头像随应用离线打包，不会在运行时访问头像地址。
- Codex Profile、MiMo 控制台等部分接口仍可能随上游变化；Token 统计可能存在按日延迟。
- Android 为主要支持平台；iOS 仍需用户自行签名，尚未完成物理设备验收。

## 下载

请从本 Release 的资产中选择对应平台和架构。Android 推荐 `arm64-v8a`；不确定架构时可选择 universal。iOS 资产为未签名 IPA，需要自行签名。
