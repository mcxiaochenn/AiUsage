# AiUsage v0.1.0

AiUsage v0.1.0 是首个正式签名的 Android 稳定版本，面向需要在本机查看 OpenAI Codex 套餐额度与 Token 使用统计的用户。

## 主要功能

- 使用 Device Code 浏览器授权，或由用户主动导入 Codex OAuth `auth.json`。
- 多账户额度概览，包括 quota windows、额外余额、无限额度和 Reset Credits。
- Profile Token 统计提供每日、每周、累计视图；热力图按上游日延迟语义显示截至昨天的数据。
- 账户注册时间缓存、English/简体中文、动态取色和完整演示模式。
- 本地优先的七天额度快照、Profile 缓存及最多 200 条脱敏同步诊断。
- 后台刷新默认关闭，启用前明确提示 Android 电池和自启动限制。

## 下载

- `AiUsage-v0.1.0-android-arm64.apk`：适用于 arm64 Android 设备的直接安装包。
- `AiUsage-v0.1.0-android-arm64.aab`：供后续应用商店提交，不可直接安装。
- `AiUsage-v0.1.0-SHA256SUMS.txt`：两个发布产物的 SHA-256 校验值。

正式产物使用 AiUsage 独立发布密钥签名，仅包含 `arm64-v8a` 与 `libai_usage_core.so`，不包含 Flutter Debug snapshot 或 Vulkan validation layer。

## 已知限制

- 当前没有自动更新器或 Google Play 发布；升级需要手动下载安装包。
- Windows、macOS、Linux 和 iOS 工程仍为实验支持，本次不提供安装产物。
- Profile 统计由账号侧异步生成，通常只应将截至昨天的数据视为完整数据，不能作为实时计费依据。
- 本项目非 OpenAI 官方产品，并依赖官方客户端使用但未向第三方承诺稳定的内部接口；上游调整可能导致登录或数据查询暂时失效。
- 从早期 Debug 签名安装切换到 v0.1.0 正式签名时需要卸载旧安装，并重新登录。
