# 路线图

本文件只记录已确认方向，不代表交付时间或兼容承诺。

## 移动端

- 完成 iOS 物理设备上的登录、Keychain、文件选择、通知和后台任务验收。
- 扩大 Android 厂商、系统版本、Provider 套餐和长时间运行覆盖。
- 调研厂商自启动、后台活动和电池“无限制”状态检测；只采用可靠的公开能力，无法检测时继续提示用户手动确认。
- 为主流厂商设置页提供经过真机验证的入口，并保留标准系统设置回退。

## 桌面端后期适配

- 逐个平台恢复 Windows、macOS 和 Linux 的 Release 构建。
- 验证安装、系统安全存储、托盘、窗口生命周期和发行版依赖。
- 完成验证前不提供桌面安装资产，也不宣称正式支持。

## Provider 与质量

- 跟踪 Codex 与 MiMo 上游变化，更新 fixture、兼容研究和解析回归测试。
- 增加 Provider schema 变化、缓存恢复、诊断脱敏和控制器边界测试。
- 后续评估余额历史图表；不把余额、额度百分比与 Token 统计混合。

## 当前不计划

Web、云同步、自建用户服务器、从浏览器抓取 Cookie、MiMo API Key 余额查询、Reset Credit 消耗、企业 Admin API 和绕过风控的自动化不在当前范围。
